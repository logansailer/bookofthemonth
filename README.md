## How to Run

### Requirements:
npm
node.js

### 1. Install and start server
from the root, run in the terminal
```
cd server
```
from this folder, run
```
npm install
npm run dev
```

### 2. Install and start Frontend
from the root, run in the terminal
```
cd botm
```
from this folder, run
```
npm install
npm run dev
```
In a web browser, navigate to http://localhost:5173 to view the application
